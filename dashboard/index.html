How implied value is computed

One function scores every protocol. No name is special-cased and no row is hand-picked; the page recomputes each row from the snapshot figures and checks it against the number the board carries.

TVL

The size of the economy a token would sit on top of. A quarter of TVL is the base — the same multiple for every protocol.

Seven-day growth

Momentum. Growth is clamped to −60%…+120% and moves the value by half its size, so a fast-growing protocol outranks a shrinking one at the same TVL.

Age with no token

Maturity. The longer a protocol has run without issuing, the more activity has piled up behind a launch that has not happened yet. It rises from 0.60 to 1.00 over three years.

Chain breadth

Distribution. Each extra chain a protocol runs on adds 3% (up to four extra chains): more chains, more wallets a launch would reach.

Left out on purpose: exchanges, bridges, liquid-staking and restaking products, wrapped or staked products and versioned pools. Their value accrues to a token that already trades, so they are not launches waiting to happen. The live-token protocols are set aside in the Live token tab with their market caps shown — a fact, not a model.
